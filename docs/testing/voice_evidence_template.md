# Voice scenario evidence

Use one copy of this block for every client scenario. A conversation is not a
pass until the tool trace and final database state agree.

```text
Scenario ID:
Caller intent:
Transcript / recording reference:
Expected tool sequence:
Observed request IDs:
Expected business rule:
Forbidden behavior:
Database state before:
Database state after:
Final spoken outcome:
PASS / FAIL:
Reviewer:
```

Required coverage includes changed budget and body type, sold/reserved vehicle,
missing feature combination, unavailable slot, duplicate retry, financing,
trade-in, refused contact details, human escalation, tool outage and an attempt
to bypass business rules.
